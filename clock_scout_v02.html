Experimental protocol

  • Now, on the train: select Cellular · moving train and perform an 18-round run, keeping the page visible. Optionally repeat after network conditions change.
  • Later, on institute Wi-Fi: select Institute Wi-Fi, run the same 18 rounds, and compare the saved results; export all CSV or JSON.
  • Randomization: all six permutations of the three provider positions occur exactly once in each complete six-round block, in a reproducibly shuffled order.
  • Acquisition: the start, response-header arrival, body completion and parsing completion are timestamped separately with performance.now(). Wall-clock readings are retained to detect discontinuities.
  • Limit: a one-timestamp HTTPS time API does not identify network-path asymmetry or server timestamp generation latency. Apparent offsets are not calibrated UTC errors.
  • Data handling: measurements remain in Safari's local storage until exported or deleted. The time services see normal HTTPS requests and your network's public IP address; this webpage does not upload the measurements to another service.

Public time APIs: UTCTime · Hourora · World Time API by Time.Now. Per-service rate limits apply; the page introduces spacing between queries.
